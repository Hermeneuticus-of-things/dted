# Raportarea vulnerabilităților

Te rugăm să nu publici detalii despre o vulnerabilitate într-un issue public.
Folosește **Security → Advisories → Report a vulnerability** din repository-ul
GitHub sau formularul privat de raportare:

https://github.com/Hermeneuticus-of-things/dted/security/advisories/new

Include pașii minimi necesari pentru a înțelege problema și versiunea afectată.
Nu atașa documente dictate, înregistrări audio, parole ori date personale.

Remedierile se prioritizează pentru versiunea stabilă cea mai recentă.
